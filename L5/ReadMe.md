# 📊 Lab 5 – Feature Engineering (Classification)

## 📌 Overview
This lab explores the impact of **feature engineering** on a classification task using a Talabat-style food delivery dataset.

The main objective is to build a model that predicts the **Order_Status** (Delivered, Cancelled, In Transit) by creating and refining meaningful features.

The dataset is already clean (no missing values or duplicates), allowing full focus on feature engineering and model performance.

---

## 🎯 Objectives
- Engineer new features to improve model performance  
- Analyze the target variable and class distribution  
- Prepare and encode features for modeling  
- Train a baseline classification model  
- Evaluate model performance  
- Interpret feature importance  

---

## 📂 Dataset
- **File:** `talabat_enhanced_orders.csv`  
- **Target Variable:** `Order_Status`  
- **Problem Type:** Classification  

### Possible Classes:
- Delivered  
- Cancelled  
- In Transit
