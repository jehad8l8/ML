- **Dataset Name:** House Prices Dataset (Ames Housing)
- **Source:** Open dataset (Ames, Iowa)

### 📌 Description
The dataset contains detailed information about residential properties in Ames, Iowa.  
It includes a mix of **numerical** and **categorical** attributes such as:

- Lot size  
- Neighborhood  
- House style  
- Overall quality  
- Year built  
- Structural and location-based features  

These attributes are used to analyze and predict housing valuation.
