# 📊 Lab 04 – Data Preprocessing & PCA

## 📌 Overview

This lab applies essential data preprocessing techniques to the **House Prices (Ames Housing)** dataset to prepare it for machine learning modeling.

The focus is on improving data quality, handling extreme values, scaling numerical features, and reducing dimensionality.

---

## 🎯 Objectives

- Detect and handle outliers using the **IQR method**
- Apply **feature scaling** (MinMax & Standardization)
- Analyze feature relationships using a **correlation heatmap**
- Perform **Principal Component Analysis (PCA)**
- Interpret explained variance ratio

---

## 📂 Dataset

- **File Used:** `train.csv`
- **Target Variable:** `SalePrice`
- **Problem Type:** Supervised Regression

---

## 🔎 Key Steps

- Outlier detection and capping  
- Feature normalization  
- Correlation analysis  
- Dimensionality reduction using PCA  

---

## ✅ Conclusion

This lab demonstrates the importance of proper preprocessing before building regression models.  
Handling outliers, scaling features, and applying PCA improves model stability, interpretability, and performance.
